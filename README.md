# Tibia 8.60 Client with DLL Mount

An updated CipSoft 8.60 client with:

- DAT/SPR support for frame groups and idle animations
- Mount system
- WASD movement with Chat On/Off
- Smart Walking On/Off
- Updated `ddraw.dll`
- `TibiaExtPatcher` for changing the server IP

## How to use

1. Keep the client files and `ddraw.dll` in the same folder as `Tibia.exe`.
2. If needed, extract the updated `Tibia.spr` from `Tibia.zip`.
3. Extract `TibiaExtPatcher.rar` and use the patcher to set your server IP.
4. Start `Tibia.exe`.
